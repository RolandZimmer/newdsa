LINEAR SEARCH

When should you use it?

Use when

  • The list is small.
  • The data is unsorted.
  • Random access is unavailable, as in a singly linked list.
  • Sorting costs more than it saves in searching.

Avoid when

  • The dataset is very large.
  • The data is already sorted.
  • The same dataset is searched repeatedly.

LINEAR SEARCH

From pseudocode to C++

PSEUDOCODE

PROCEDURE Linear_Search(Array, Target_Value)
  FOR i = 0 TO length(Array) - 1
    IF Array[i] = Target_Value THEN
      RETURN i
    END IF
  END FOR
  RETURN -1
END PROCEDURE

C++

int linear_search(int a[], int n, int val) {
    for (int i = 0; i < n; i++) {
        if (a[i] == val) return i;
    }
    return -1;
}

BINARY SEARCH

Required: sorted data

Best suited for

  • Large, sorted datasets.
  • Static or rarely changing data.
  • Arrays or vectors with O(1) random access.
  • Boundary queries: first, last, insertion point, or nearest value.

Less suitable

  • Unsorted or frequently changing data.
  • Linked lists without fast access to the middle element.
  • Very small datasets.
  • Finding all duplicates without a boundary-search variant.

BINARY SEARCH

Iterative C++ implementation

int binarySearch(int arr[], int n, int x) {
    int low = 0, high = n - 1;
    while (high >= low) {
        int mid = low + (high - low) / 2;
        if (x == arr[mid]) return mid;
        else if (x > arr[mid]) low = mid + 1;
        else high = mid - 1;
    }
    return -1;
}
mid = left + (right - left) / 2avoids overflow compared with (left + right) / 2

03 — INTERPOLATION SEARCH

Estimate first.
Then narrow down.

Instead of always checking the midpoint, interpolation search estimates a position from the target value and the values at both ends of the range.

Like opening a directory near “Y” instead of at the exact middle.

pos = low +
(x − a[low]) × (high − low)a[high] − a[low]

INTERPOLATION SEARCH

Fast — when the data fits

Use when

  • The array is sorted.
  • Values are approximately uniformly distributed.
  • A large dataset is searched repeatedly.
  • Random access is available.
AverageO(log log n)

Avoid when

  • Values are skewed or clustered.
  • The array is unsorted.
  • The dataset is small.
WorstO(n)

INTERPOLATION SEARCH

C++ implementation

int interpolation_search(int arr[], int n, int x) {
    int low = 0, high = n - 1;
    while (low <= high && x >= arr[low]
                       && x <= arr[high]) {
        if (arr[low] == arr[high])
            return arr[low] == x ? low : -1;
        int pos = low + (1LL * x - arr[low]) *
            (high - low) / (1LL * arr[high] - arr[low]);
        if (arr[pos] == x) return pos;
        else if (arr[pos] < x) low = pos + 1;
        else high = pos - 1;
    }
    return -1;
}

Division method

Choose m carefully. Powers of the number base can give the rightmost digits too much influence.

A prime table size often gives a better distribution.

HASH FUNCTIONS

Multiplicative method

h(k) = ⌊m · frac(k·A)⌋

Knuth's suggested constant: A = (√5 − 1) / 2 ≈ 0.6180339887

m × frac(k·A)⌊…⌋ = h(k)

Unlike the division method, the table size m doesn't need to be prime here — the multiplication step already spreads keys out.

Only the fractional part of k·A matters, so consecutive keys still land far apart.
